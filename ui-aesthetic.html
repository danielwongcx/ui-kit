畫過10,000+張 UI 高保真，我的設計審美心得（1）：8 條原則 + 5 個常用 AI 設計 Skill

我做了 10 年 UI/UX 設計，前前後後畫了上萬張高保真。AI 做出來的頁面，常常一眼就能認出來：紫藍漸變、居中排版、卡片套卡片。工具變了，判斷沒變。

5 個設計 Skill 實測

挑了 GitHub 上星數最多的 5 個，每個都配上使用場景。演示是按各 Skill 官方 README 描述的工作方式復刻的，用來說明能力，不是 Skill 的真實運行結果。

UI UX Pro Max Taste Skill Impeccable Emil Hallmark

1 UI UX Pro Max

一句話需求，自動配出整套設計系統

能力

內置 192 條行業規則、79 種風格、192 套配色、74 組字體搭配、34 種落地頁結構，支持 22 種技術棧。

演示

同一句「幫我做個落地頁」，換成三個行業。它先匹配行業，再選出頁面結構、風格、配色和字體，列出要避免的做法和交付前檢查清單，最後才寫頁面。

怎麼用

npm install -g ui-ux-pro-max-cli
uipro init --ai claude

裝好後直接提需求，它會自動觸發：「幫我給山間溫泉 SPA 做一個落地頁，目標客戶是週末來放鬆的白領」。

適合

不知道該用什麼風格，想要穩妥、專業、符合行業習慣的結果。

2 Taste Skill

先定方向，再做出原創感

能力

基於 247 個精選網站的研究，提煉出 20 個設計方向。它先從你的素材裡找出「只有你有的東西」，發 3 個方向給你挑，用開放圖庫的真圖搭頁面，最後在瀏覽器裡按 3 種寬度截圖自查，最多返工 3 輪。

演示

給老城區咖啡烘焙坊「慢烘」做官網。店主以前是排字工，於是有了「活字印刷」方向：整個官網排成一張鉛印的豆單。

怎麼用

npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"

需求裡多給你獨有的素材：「用 taste skill 給咖啡烘焙坊『慢烘』做官網。店主以前是排字工，店在鼓樓西巷 37 號，每週四烘豆。」

適合

官網、品牌頁、作品集。注意：跑一次要 30–45 分鐘，需要 Node 22+ 和 Chrome。

3 Impeccable

用命令把頁面一塊塊修好

能力

24 個設計命令，加 62 條不靠大模型的 AI 味檢測規則。先用 init 把產品定位寫進 PRODUCT.md，之後每條命令都會參考它。

演示

一個 AI 默認生成的白板產品首頁。先運行 /impeccable audit，標出 7 處問題。

怎麼用

npx impeccable install

每個項目先運行 /impeccable init，之後按「命令 + 範圍」使用：/impeccable audit landing、/impeccable polish settings。

適合

已有項目，想逐塊打磨。注意：它不替你定方向，往大膽還是克制的方向調，要你自己判斷。

4 Emil Kowalski Skills

動效和細節的手感

能力

作者曾在 Vercel、Linear 工作，也是 Sonner 的作者。15 個小 Skill，專門管 AI 最容易做錯的細節。

演示

筆記 App 裡的四個小交互，左邊是 AI 默認寫法，右邊按 Emil 的規則。

  • 進場動畫用 ease-out，不用 ease-in，一開始就有反應，感覺更快。
  • 下拉菜單從按鈕的位置長出來，從 0.96 開始縮放，而不是從 0。
  • 按鈕按下縮到 0.97，有手感。
  • 提示疊成一摞，不把內容擠下去。
  • 長名字截斷，大數字縮寫，不把卡片撐破。

怎麼用

npx skills@latest add emilkowalski/skills

按名字調用：「用 review-animations 檢查這個下拉菜單」「用 break-ui 拿極端數據測一下用戶卡片」。

適合

疊加在其他 Skill 上，專門補動效和細節。

5 Hallmark

不過檢查不能上線

能力

48 種主題材質，頁面圍繞用戶要做的事來排。sloplint 分三級檢查：Floor 不過不能上線，Reflex 是模型的慣性，Finish 是細節。改版時核對鏈接、表單、事件一個不少。

演示

預約制茶室「一盞」的預約頁。頁面的任務是訂位子，所以預約卡放在首屏。

怎麼用

npx skills add nutlope/hallmark -g

新做一頁：/hallmark 給預約制茶室做預約頁；改版舊頁面：/hallmark redesign ./src/app；只檢查不改：/hallmark audit ./index.html。

適合

落地頁、預約頁、商店頁，以及有風險的改版。

怎麼選

  • 不知道用什麼風格 → UI UX Pro Max
  • 想要原創感 → Taste Skill
  • 已有項目，想逐塊打磨 → Impeccable，再配上 Emil
  • 改版舊站，怕改壞功能 → Hallmark

AI 生圖對比

演示頁面裡有 8 張圖不是代碼畫的，是生成的，用在 UI UX Pro Max 和 Hallmark 兩個演示裡。

流程是這樣的：AI 先看頁面，判斷哪裡缺圖，寫好提示詞；我用 Codex / GPT 生成；再交回給 AI 壓縮、嵌進頁面，並按圖調整排版。

8 條原則

把上面的過程提煉成可以複用的原則：

  1. 1從好作品和日常裡找需求

    多看優秀作品，同時留意自己工作和生活裡反覆遇到的麻煩，把兩邊對照起來看。

  2. 2先定義，再動手

    先寫清楚給誰用、解決什麼問題、要給人什麼感覺。寫不清就讓 AI 來問你，這一步不讓它出設計。

  3. 3拆解好設計，不照搬

    看到好作品，先說出它好在哪。只學原理，不複製畫面。

  4. 4用目標給反饋

    在截圖上標出問題，說清楚想要的效果，具體數值交給 AI。

  5. 5先出全貌，再逐塊改

    • 先讓 AI 出一版完整頁面。
    • 列出問題，按重要程度排序。
    • 每輪只改一處，確認後再改下一處。

  6. 6統一視覺規則

    色值、字體、材質先定好，生圖提示詞裡也寫明，同一組素材放在一個對話裡連續生成。

  7. 7先上線，再優化

    不影響核心體驗的問題，不阻塞發佈。上線後根據真實反饋決定下一步改什麼。

  8. 8用反饋分配精力

    • 新想法先做成小 demo 試水。
    • 反饋好的持續打磨，反饋差的及時停掉。
    • 設計以外的能力也要補上：寫介紹、做推廣、維護用戶。
