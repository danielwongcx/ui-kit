Select

Native customizable <select> via appearance: base-select (Chromium 135+). Rich HTML inside <option>, <optgroup> grouping, <selectedcontent> for the closed preview, and ::picker(select) / :open for the popup — no JS dropdown library.

Glow border

@property --a registers an angle. That angle drives a conic-gradient on the shell behind the card, and a blurred copy of the same gradient glows outside the rim. The inner panel is a solid dark fill, so the rainbow reads as a thin border. Pure CSS — no JS. Reduced motion holds the rim still.
