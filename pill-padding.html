Buttons

Pill padding

Equal left and right padding on a full pill misses twice. The icon sits off the round cap, and the curve cuts the end, so 16px of padding reads as optical space of about 12.

CSS from Haz (@diegohaz).

This plate needs CSS lh, cap, and pi. The rules below are still the ones to copy.

Labels are measured pixels, rounded. The plate is 1rem Inter with line-height 1.5. The copied CSS leaves the font alone.

How the padding fails, and the fix

01

Off center

The round cap is a circle whose center sits half the button height in from the end. An icon of 1lh with 1em of padding on both sides lands past that center. At --py: 0.5em the miss is 8px. The icon’s edge is --py - --px, which pulls it back until the ring matches the block padding.

The gap stays max(--py, --px - (1lh - 1cap) / 2). At this plate that reads 10, from the space above the cap in the line box.

02

Cut area

Each rounded corner drops a square minus a quarter circle, r²(1 − π/4). The two corners on one end, spread across the button height, leave a strip r²(1 − π/4) / --pill. On a full pill that strip is r(1 − π/4), about 0.2146 of the radius, about 4px here. Padding of 16 reads as optical space of 12. CSS pi is the Values Level 4 constant.

03

Real radius

--pill is --py + 0.5lh, the real half-height. --r has to be --pill, or a smaller radius you actually draw, such as 16px. The label margin multiplies by --r / --pill. With --r left at 999px, that margin is about 10,700px at the default padding.

04

Same rules

An icon on the right, text at both ends, and an icon alone use the same first-child and last-child margins. Text at both ends reads geometric 20 and optical 16. An icon alone reads 8 all around. --py: 0.7em reads 11 all around, gap 11, end 21. --r: 16px reads end 19. Optical space stays 16.

The CSS

button {
  --py: 0.5em;
  --px: 1em;
  --pill: calc(var(--py) + 0.5lh);
  --r: var(--pill);
  padding: var(--py) var(--px);
  gap: max(var(--py), var(--px) - (1lh - 1cap) / 2);
  border-radius: var(--r);
}
button > :first-child { margin-inline-start: var(--edge); }
button > :last-child { margin-inline-end: var(--edge); }
.icon {
  width: 1lh;
  height: 1lh;
  --edge: calc(var(--py) - var(--px));
}
.label {
  --edge: calc(var(--r) * (1 - pi / 4) * var(--r) / var(--pill));
}

The wrong plate keeps this padding and this gap, sets --r to 999px, and skips the edge margins.
