Locked rules + named motion primitives.

Prompt Spec

A reusable system prompt that locks spacing, radius, type, and color ratios, then names five interruptible real-UI motion primitives so a model cannot treat ‘beautiful’ or ‘clean’ as a spec.

Summary

Asking for a “beautiful, clean interface” gives the model no rules, so spacing, radius, type, and color ratios get reinvented every time.

Lock a rules file first; every AI must read it before any UI work. It may not invent tokens or use adjectives as design decisions.

Paste the Rules block, or point the model at DESIGN.md / tokens. Paste the System prompt. Then replace only the last line:

Now build: [this screen]. Use primitive(s): [names].

These primitives are for real product UI (user-driven, interruptible). They are not a pre-timed film. No camera dolly, no fake hand cursor, no 3D flips.

Primitives

  1. expand-to-sheet — A card morphs into a modal sheet (shared bounds); backdrop fades ~300ms; dismiss is the reverse morph.
  2. confirm-and-collapse — Primary black pill CTA; on success, row checkmarks stagger in, then the sheet collapses; optional list-insert of a new activity row.
  3. tab-or-filter-swap — The selected pill slides; outgoing list fades/down 150–200ms; incoming list fades/up, stagger 40–80ms. No FLIP if the item set is different.
  4. chart-period-swap — The hero number ticks; the chart path-morphs in ~400ms; a black tooltip follows the scrub.
  5. chip-update — Adding or removing a filter chip uses the same list swap; counts update with it.

Rules

Paste this, or point the model at DESIGN.md / tokens, before any UI work.

Spacing scale (only): 4 8 12 16 24 32 48 64 96 128. Do not invent other gaps or padding.

Radius (three steps):
- Cards: 20–24
- Icon buttons / squircles: 16–20
- Pills and the primary CTA: fully round
- Nested radius: inner = outer − padding, 4px grid, floor 4

Type (three steps): page title, hero number, body / meta (gray). Do not add a fourth display size.

Color usage ratio: about 90% neutrals (canvas + cards), 8% ink hierarchy, 2% accent.
- Canvas: soft light gray; cards: white
- Orange only for overdue, sparklines, and due dates
- Green only for success
- Primary CTA is a black pill
- Do not add a third accent color

Do not invent spacing, radius, type, or colors.
Do not treat “clean”, “beautiful”, or “modern” as a design decision.
