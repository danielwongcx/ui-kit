# ui-kit

A self-contained HTML UI library gallery (digit scroll springs, glow buttons, nested-radius cards, and page-shell palettes).

Open `index.html` locally by double-clicking it, or from this folder run `python3 -m http.server` and visit the URL it prints.

`index.html` and `ui-combo.html` are the same gallery. Digits, Buttons, and Cards are unchanged. Palettes adds ten page-shell themes; Forest is the default, and only the page background switches.

`digest.html` is a separate searchable catalog of repo digests.
