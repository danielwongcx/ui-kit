04 · Effects

A 1 px ring, then depth, then brand.

The first layer is always a 1 px ring instead of a border. elevation/ adds depth. state/ adds the brand for interaction.

shadow

Effect colour only. Used inside effect styles.

06 · Rules

What every screen follows.

Colour

  • Layers use Tokens or Theme, never Foundations.
  • Brand only on primary buttons, the active menu item, links, selection and the focus ring.
  • Neutrals and status colours never change with the brand.
#462CF2
primary-base

Hover both. Only the token moves to primary-dark.

Contrast

  • Text 4.5:1, icons and borders 3:1 (WCAG 2.2 AA).
  • Coloured text uses …/text; icons use …/base.
  • Status never relies on colour alone: always an icon or a label.

Type

  • One-line text in a box → Trim set.
  • Multi-line text → normal set.
  • Never change a trimmed layer’s typography by hand.

Layers

  • Names are lowercase with hyphens: search-field, task-card.
  • Icons keep their library name: lucide/search.
  • Frames without a shadow never clip content.
