Layer 4 · Blocks

A screen is a stack of blocks.

A block is a section pulled from a real screen, once you notice you are building it again. A run card, an approval panel, a task row. If nothing you have covers the screen, slow down and ask if it belongs.

Layer 5 · Rules and skills

A sentence with a reason. A file for a task.

Rules live in the file the agent always reads. A rule is one sentence and the reason. Write it when the agent gets that thing wrong. A skill is the instructions for one task. A good skill is one two people would follow the same way.
